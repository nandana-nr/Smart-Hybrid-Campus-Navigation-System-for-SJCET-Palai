SJCET NAVIGATOR — AERIAL UI PROTOTYPE

Files:
- index.html
- styles.css
- app.js
- sjcet-aerial.jpg

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. For browser geolocation/advanced features, use a local server (for example VS Code Live Server).

Included:
- Full-screen SJCET aerial campus background
- SJCET Navigator header and navigation logo
- Map / Facilities / Events / Admin Login
- Destination search and popular destinations
- QR-assisted indoor initialization UI
- Route/ETA card
- Geolocation button
- Zoom/recenter controls
- Responsive layout

IMPORTANT:
This is a frontend prototype. The admin login is intentionally demo-only and must be replaced by secure backend authentication before deployment. Route values are demo values until the actual surveyed campus graph and A* routing backend are connected.

The supplied aerial image is used as the visual campus layer. The final navigation system can later place interactive route markers/paths on top of this layer using the project's surveyed campus coordinates/graph.
